リサーチャーの初仕事：価格チェック速報

service.33l.jp とマカセル（officeplata.com/makaseru）の現在の料金を、Webで公開されている全国の相場と比べました。相場の数字は東京の会社が多めなので、鹿児島・宮崎ではこれより低めに出やすい点に注意してください。

サービスいまの価格（仮）世間の相場判定リサーチャーの提案
レンタルさっさー3,300円（税込）／30分地方のIT・経営相談で1時間5,000〜10,000円妥当（安め）入口の商品なので据え置きでよい。成約時に相談料を充当する形にすると次へ進みやすい
LINE公式運用サポート10,000円（税別）／月運用代行は小規模店向けで月1〜3万円、一般的には月5〜30万円妥当相談と添削だけなら相場並み。配信代行まで含む上位プラン（月3万円前後）を足す余地あり
顧問 スタンダード100,000円（税別）／月中小企業向けの顧問で月10〜30万円、実装込みの伴走で月10〜35万円構築込みでは安い初月にLINE受付・Lark BASE・管理画面まで作るのに相場の下限。最低契約期間（相場は3〜6ヶ月）か初期費用を設けないと、短期解約で構築費を回収できない
顧問 フルサポート250,000円（税別）／月同上（月10〜35万円）妥当相場の中〜上。業務全体の設計と引き継ぎまで含む内容と釣り合っている
導入伴走パッケージ50万円〜（税別）／3ヶ月プロジェクト型で50〜200万円、初期コンサルで40〜200万円妥当（下限）地域価格としては適正。「〜」の上限の目安を示すと見積の説明がしやすい
実行定着パッケージ120万円〜（税別）／6ヶ月同上。月あたり20万円は伴走型の相場内妥当デジタル化・AI導入補助金の対象になるか（ITツール登録が要る）を確認して、使えるなら提案に入れる
マカセル（Claude Code マンツーマン伴走）
単発レッスン30,000円（税別）／90分Claude Code の法人向け対面研修で1ステップ10万円〜妥当お試しとして手頃。竹・松へ移ると差し引く仕組みも入口として良い
梅20,000円（税別）／月個人メンター（MENTA）の平均契約は月1.4万円前後妥当一般的なメンターより少し高いが、現役の受託開発者でClaude Code特化なら説明できる
竹50,000円（税別）／月上記の間。同条件の比較先は少ない妥当おすすめプランとして梅と松の間にうまく収まっている
松100,000円（税別）／月経営者向け Claude Code 個別指導（週1×60分）で月25万円（東京の会社）安い同じ週1回に直接修正2時間まで付いて半額以下。限定3枠なら月15万円前後まで上げる余地あり

これはWeb検索で拾える公開情報だけの速報です。次の段階では、市場リサーチャーが鹿児島・宮崎のLark／LINE支援会社の料金を一覧にし、マーケターがLPの打ち出し方を提案します。いちばん大きなリスクは料金より「質問し放題」の対応量で、受講者が増えると返信期限を守るのが代表1人では難しくなります。そのためマカセル講師アシスタントを置いています。

CFOとマネーフォワードをつなぐ

マネーフォワード クラウド会計は2026年3月に公式のMCPサーバーを全プラン向けに公開しました。Claudeにつなぐと、CFOが仕訳・試算表・取引先を直接読めるようになります。

CFOに任せること
  • 毎月の損益と前年同月比
  • 入金予定と未回収の一覧
  • 3ヶ月先までの資金繰り予測
  • サービス別の売上構成
最初はさせないこと
  • 仕訳の登録・修正（読むだけで始める）
  • 税務の判断（税理士さんに確認）
  • 振込などお金を動かす操作
つなぐ手順
  • claude.ai の設定 → コネクタでマネーフォワードのMCPを追加
  • マネーフォワードにログインして許可
  • CFOの指示書に「読むだけ」のルールを書く

参考：マネーフォワード クラウド 開発者サイト（MCPサーバー）
