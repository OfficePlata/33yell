# 第1回 オリエンテーション／作りたいものを言葉にする

## この回のゴール
- 講座でどこまで作れるようになるか、全体像がわかる
- 自分の業務から「作りたいもの」候補を1つに絞れている

## タイムテーブル
| 時間 | 内容 |
|---|---|
| 0:00〜0:10 | 自己紹介（名前・会社・今いちばん面倒な業務を1つ） |
| 0:10〜0:20 | 説明① 講座の全体像と、作れるものの実例 |
| 0:20〜0:40 | ハンズオン① 業務の棚卸し |
| 0:40〜0:50 | 説明② 「困りごと → しくみ」に変える考え方 |
| 0:50〜1:10 | ハンズオン② 作りたいもの候補を3つ出し、1つに絞る |
| 1:10〜1:30 | 共有・質問・宿題 |

## 説明① 講座の全体像
- この講座では「Lark＝社内の整理」「AI＝作る・考えるの相棒」を道具に使います。最後にお客様との接点として「LINE」もつなぎます。
- 作れるものの例（ささエールの支援実績の型）
  - お店の予約・受注管理（LINEで受付 → Lark BASEで管理 → スタッフに通知）
  - 社内ポータル（スタッフの申請・シフト・お知らせ）
  - 顧客管理（CRM）、工程管理、問い合わせ管理
- 進め方は「まずコードを書かずにLarkで作る → 足りない部分だけAIにコードを書かせる」です。

## ハンズオン① 業務の棚卸し
[../worksheets/01-design-sheet.md](../worksheets/01-design-sheet.md) の「1. 業務の棚卸し」を使います。

1. 1週間の仕事を思い出し、くり返している作業を10個書き出す
2. それぞれに「誰が」「どのくらいの頻度で」「何を使って（紙・Excel・電話・LINEなど）」を書く
3. 「面倒」「ミスが起きる」「人に聞かないとわからない」に当てはまるものに印を付ける

## 説明② 困りごとを「しくみ」に変える
困りごとは、だいたい次の4つの型に分けられます。

| 型 | よくある困りごと | しくみの形 |
|---|---|---|
| 集める | 電話・紙・LINEなどバラバラに届く | 入力フォーム（入口を1つに） |
| 貯める | Excelが人ごとにある、最新がわからない | Lark BASE（台帳を1つに） |
| 知らせる・回す | 伝え忘れ、承認待ちで止まる | 自動化・Bot通知・承認 |
| 見る | 今月の数字がすぐ出ない | ビュー・ダッシュボード |

最初に作るものの選び方：**「毎週くり返す」「関わる人が2〜5人」「失敗しても大事故にならない」** ものから選ぶと進めやすいです。

## ハンズオン② 1つに絞る
1. 印を付けた作業から、候補を3つ選ぶ
2. 3つを「効果の大きさ」「作りやすさ」で○△×を付ける
3. 1つに決め、設計シートの「2. 作りたいもの」に一言で書く（例：「電話予約をフォーム受付にして、BASEで管理する」）

決められない方は、共通サンプル「まなべ食堂」で進めて大丈夫です。

## AIへの頼み方の例（家で試す）
```
あなたは中小企業の業務改善の相談相手です。
私の会社は「（業種）」で、従業員は（人数）名です。
次の業務の中から、Larkで最初にしくみ化すると効果が出やすいものを、理由とあわせて上位3つ挙げてください。
（棚卸しした業務を貼り付け）
```
