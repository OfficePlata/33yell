# 第3回 Larkの基本を使いこなす

## この回のゴール
- Larkの主な機能と、どの情報をどこに置くかがわかる
- 講座用のWikiスペースを作り、設計シートを置けている

## 説明① Larkの全体像
| 機能 | ひとことで | この講座での使い方 |
|---|---|---|
| メッセンジャー | 社内チャット | 講座グループ、通知の受け取り先 |
| Docs | 共同編集できる文書 | 設計シート・議事録 |
| Wiki | Docsを本棚のように整理 | 自社のマニュアル・ルールの置き場 |
| BASE | データベース（台帳） | 業務アプリの中心（第4回〜） |
| 承認 | 申請・承認の流れ | 第6回で使う |
| カレンダー | 予定共有 | 予約・シフトとの連携 |

※ 画面の名前や場所は、Larkのバージョンや言語設定で少し変わることがあります。

## ハンズオン① グループとDocs
1. メッセンジャーで「マナベル_（自分の会社名）」というグループを作る
2. Docsで新しい文書を作り、第2回の設計シートを貼り付ける
3. 文書の共有設定を開き、「誰が見られる／編集できるか」を確認する
4. グループにDocsのリンクを送り、メンションとコメントを1回ずつ試す

## 説明② 情報の置き場所を決める
迷ったら次のルールで置きます。

| 情報の種類 | 置き場所 |
|---|---|
| 流れていってよい連絡 | メッセンジャー |
| 残しておく文章（手順・ルール・議事録） | Wiki（Docs） |
| 件数が増える・一覧で見たい・集計したいもの | BASE |

「チャットで送った大事なことが流れて見つからない」は、Wikiに置き直す合図です。

## ハンズオン② Wikiの目次を作る
1. Wikiで新しいスペース「（会社名）しくみづくり」を作る
2. 次の目次でページを作る
   - 00 はじめに（このスペースの使い方）
   - 01 作りたいもの設計シート ← Docsを移動
   - 02 業務ルール
   - 03 操作マニュアル
   - 04 改善メモ
3. AIに「00 はじめに」の文章を下書きしてもらい、貼り付ける

## 宿題
- 社内で使っているExcel・紙の帳票を1つ集め、Excelまたは写真で用意する（第4回で取り込みます）
