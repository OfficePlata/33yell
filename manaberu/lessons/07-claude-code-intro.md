# 第7回 Claude Code入門

## この回のゴール
- 自分のPCで Claude Code を動かし、Webページを1枚作らせられる
- 修正を頼み、Gitで記録して GitHub に保存できる

## 準備（事前に）
- Claude の有料プラン（Pro以上）に加入済み（利用料は受講者負担）
- GitHub アカウントを作成済み
- Windowsの方：講師から案内する手順で事前インストールを済ませておく（[../worksheets/00-preparation-checklist.md](../worksheets/00-preparation-checklist.md)）

## 説明① Claude Codeとは
| | チャットAI（Claude・ChatGPT） | Claude Code |
|---|---|---|
| どこで使う | ブラウザ・アプリ | PCのターミナル（文字で操作する画面）やエディタ |
| 何ができる | 答えを文章で返す | **PCのフォルダの中のファイルを、直接作る・直す・動かす** |
| たとえ | 相談相手 | 隣に座ってPCを操作してくれる開発者 |

最低限おぼえる言葉
| 言葉 | 意味 |
|---|---|
| フォルダ（ディレクトリ） | 作るもの1つ分の箱。1つのアプリ＝1つのフォルダ |
| ターミナル | 文字で命令する画面。Claude Codeはここで動く |
| HTML / CSS / JavaScript | Webページの「中身／見た目／動き」 |
| Git | 変更の記録（ゲームのセーブポイント）。いつでも前に戻れる |
| GitHub | Gitの記録をネット上に保管する場所 |

## ハンズオン① 最初の1ページ
1. ターミナルを開き、Claude Code をインストールする（公式の最新手順は講師が当日案内します）
2. 作業用フォルダを作り、その中で `claude` と入力して起動、ログインする
3. 次のように頼む
   ```
   まなべ食堂（架空の定食屋）の紹介ページを、index.html 1枚で作ってください。
   スマホで見やすく、温かみのある色合いで。営業時間・メニュー3品・地図の代わりの住所欄を入れてください。
   ```
4. できた index.html をブラウザで開いて確かめる
5. 「ボタンの色を緑に」「メニューを5品に」など、2回修正を頼む

## 説明② 頼み方の型とセーブポイント
Claude Codeへの頼み方は、チャットAIの「や・も・ざ・か」に3つ足します。
- **小さく頼む**：「全部作って」ではなく、1回1機能
- **確かめ方を伝える**：「できたら、どこを開けば確認できるか教えて」
- **わからないことは先に聞いてもらう**：「作る前に、不明点を質問してください」

Gitの使い方は、まずClaude Codeに頼めば大丈夫です。
```
今の状態をGitで記録してください。メッセージは「紹介ページの初版」で。
```
- 動いた！と思ったら記録する。壊れたら「1つ前の記録に戻して」と頼めます。

## ハンズオン② GitHubに保存する
1. GitHubで新しいリポジトリ（保管場所）を作る。**公開範囲は Private** にする
2. Claude Codeに「このフォルダをGitHubのリポジトリ（URL）にアップロードしたい。手順を教えて、できるところは実行して」と頼む
3. GitHubの画面で、ファイルが見えることを確かめる

## 守ること
- Claude Code がコマンドの実行許可を求めてきたら、**何をするのか読んでから** 許可する。わからなければ「このコマンドは何をしますか？」と聞く
- パスワードやAPIキーを、チャット欄やファイルに直接書かない（第9回で正しい置き場所を学びます）

## 宿題
- 紹介ページに自社（または題材）の紹介文を入れ、3回以上「修正 → 記録 → GitHubに保存」をくり返す
