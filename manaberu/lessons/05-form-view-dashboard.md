# 第5回 フォーム・ビュー・ダッシュボード

## この回のゴール
- 「入力の入口（フォーム）→ 一覧（ビュー）→ 集計（ダッシュボード）」がそろっている

## 説明① 入力の入口を1つにする
- BASEのフォームビューを使うと、テーブルに直接つながった入力フォームが作れます。
- 社内のメンバーだけでなく、共有設定によっては社外の人にも入力してもらえます（共有範囲は必ず確認）。
- 入力ミスを防ぐ工夫：必須にする、選択肢にする、説明文を書く。

## ハンズオン① フォームを作る
1. 予約（または自社の主テーブル）でフォームビューを追加する
2. 入力してほしい項目だけを表示し、順番を入れ替える
3. 必須項目と説明文を設定する
4. スマホでフォームを開き、実際に3件入力して、テーブルに入ることを確かめる

## 説明② 見え方を変えるビューと集計
| ビュー | 向いている使い方 |
|---|---|
| 表（グリッド） | 全体の一覧、編集 |
| かんばん | ステータスごとの進み具合（受付→確定→来店済） |
| カレンダー | 日付で見る（予約・締切） |
| ギャラリー | 写真付きのカード（商品・物件） |
| ガント | 期間のある作業・工程 |

- ビューごとに **絞り込み・並べ替え・グループ化** を保存できます。「本日の予約」「自分の担当分」など、使う人ごとに作ります。
- ダッシュボードでは、件数・合計・グラフを並べて数字を一目で見られます。

## ハンズオン② ビューとダッシュボード
1. かんばんビューを作り、ステータスでグループ化する
2. 「本日の予約」「今週の予約」など、絞り込み済みのビューを2つ作る
3. ダッシュボードを作り、「今月の件数」「ステータス別の件数（グラフ）」「受付経路別の件数」を置く
4. ビューとダッシュボードの使い方を、Wikiの「03 操作マニュアル」に1ページ1操作で書く（AIに下書きさせてよい）

## 宿題
- 社内の誰か1人にフォームを使ってもらい、わかりにくかった点を聞いて直す
