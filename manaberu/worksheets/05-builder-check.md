# 構築者チェック（第12回）

マナベルの修了時に、「構築者」としてどこまでできているかを確かめる表です。受講者が自己評価し、第12回で講師と一緒に確認します。

判定：◎ 1人でできた／○ 手順やAIを見ながらできた／△ 講師の助けが必要だった

| # | 構築者の力 | 確かめること | 証拠（見せるもの） | 自己 | 講師 |
|---|---|---|---|---|---|
| 1 | 聞き取る・決める | 関係者の困りごとを聞き、作るものと「成功の目安」を決めた | 設計シート | | |
| 2 | Larkで組む | テーブルを分けてリンクし、フォーム・ビュー・ダッシュボードを作った | BASEの画面 | | |
| 3 | 回す | 自動化（通知・リマインド・承認のいずれか）が本番で動いている | 自動化の一覧表 | | |
| 4 | AIで作る | Claude Code に頼んでアプリを作り、修正し、公開した | 公開URL・GitHubの記録 | | |
| 5 | つなぐ | アプリ（またはLINE）からの入力がBASEに入り、社内に通知される | デモ | | |
| 6 | 守る | 秘密情報がコード・GitHubにない。権限と個人情報のルールがある | 運用ルール表 | | |
| 7 | 育てる | 改善要望を受けて直し、公開し、記録した | 改善メモ | | |
| 8 | 伝える | 作ったものを社内の人に説明し、使い方を教えた | 操作マニュアル・発表 | | |

## 修了の目安【仮】
- 8項目すべてで △ 以上、かつ ◎ が4つ以上
- 目安に届かなかった項目は、修了後1ヶ月の [定着チェック](04-retention-checklist.md) で再確認します
