# 共通サンプル：まなべ食堂の予約・注文管理

作りたいものがまだ決まらない方は、この架空のお店を題材に進めます。自社の題材がある方も、各回の手順の「例」としてこのサンプルが出てきます。

## お店の設定（架空）

- まなべ食堂：席数20席の定食屋。店主＋スタッフ3名
- 今の困りごと
  1. 電話予約をメモ帳に書いていて、ダブルブッキングが起きる
  2. お弁当の大口注文（10個以上）を口頭で受けていて、作り忘れが怖い
  3. 常連さんの好み・アレルギーが店主の頭の中にしかない

## 講座を通して作るもの

| フェーズ | 作るもの |
|---|---|
| 1 | 困りごとの整理と、作りたいもの設計シート |
| 2 | Lark BASE「まなべ食堂 台帳」：顧客／予約／弁当注文 の3テーブル、予約フォーム、本日の予約ビュー、売上ダッシュボード、新規予約のBot通知 |
| 3 | 予約受付ページ（Cloudflare Pagesで公開）→ 入力内容がBASEの「予約」テーブルに入る |
| 4 | LINE公式アカウントのリッチメニューから予約ページ（LIFF）を開き、予約するとスタッフのLarkグループに通知が届く |
