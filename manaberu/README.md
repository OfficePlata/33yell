# マナベル — AI × Lark で「自社のしくみ」を自分で作れるようになる講座

> 「作ってもらう」から「自分で作れる」へ。
> Lark と AI を道具に、自社のサービスやアプリを形にする力を身につける講座です。

運営：ささエール（Office Plata）／講師：笹原 彰朗

---

## 1. この講座で目指すこと

講座を終えたとき、受講者が次の状態になっていることをゴールにします。

| # | できるようになること | 確かめ方 |
|---|---|---|
| 1 | 自社の業務から「作るべきもの」を見つけ、AIと一緒に要件（何を・誰が・どう使うか）を1枚にまとめられる | 作りたいもの設計シートが完成している |
| 2 | Lark BASE で、データの入れ物・入力フォーム・一覧画面・ダッシュボードを、コードを書かずに作れる | 自社用のBASEが動いている |
| 3 | Lark の自動化・Bot通知・承認を組み合わせ、「入力されたら知らせる・回す」流れを作れる | 自動化が1本以上本番で動いている |
| 4 | Claude Code に頼んでWebページ・アプリを作り、インターネットに公開できる | 公開URLがある |
| 5 | 作ったアプリと Lark BASE を API でつなぎ、データを読み書きできる | アプリから入力したデータがBASEに入る |
| 6 | 権限・個人情報・秘密情報（APIキー）に気をつけて、運用・改善を続けられる | 運用ルール表がある |

最終回では、受講者それぞれが **自社のサービス・アプリを1つ公開して発表** します。

## 2. こんな方に

- 自社の業務を Lark で整えたいが、どこから手をつければよいか迷っている方
- 予約・受付・顧客管理・社内申請などを「自分たちの手で」作れるようになりたい方
- 外注すると高い・直すたびに頼むのが大変、と感じている方
- AI（ChatGPT・Claude など）を触ってはみたが、仕事の「しくみ作り」にまで使えていない方
- プログラミング未経験の方も対象です（PCで文字入力・ファイル保存ができれば大丈夫です）

## 3. 全体マップ（4フェーズ・全12回）

```
フェーズ1 土台をつくる        フェーズ2 Larkで作る          フェーズ3 AIで作る            フェーズ4 サービスにする
（第1〜3回）                  （第4〜6回）                  （第7〜9回）                  （第10〜12回）
作りたいものを言葉にする  →  BASEで業務アプリを作る   →  Claude Codeでアプリを作る →  LINEとつなぎ、安全に運用
AIと話す型を覚える            フォーム・一覧・集計          Webに公開する                 成果発表
Larkの基本を使いこなす        自動化・通知・承認            Lark BASEとAPIでつなぐ
```

- **コードを書かずに作れる範囲（フェーズ2）を先に広げる** → それでも足りない部分だけを **AIにコードを書かせて作る（フェーズ3）**、という順番です。
- 全12回を通して、受講者は **自分の「作りたいもの」1つ** を育てていきます。題材が決まらない方向けに、共通サンプル「まなべ食堂の予約・注文管理」を用意しています（[sample-project.md](sample-project.md)）。

詳しい回ごとの内容は [curriculum.md](curriculum.md) を見てください。

## 4. 1回の進め方

1回90分。「聞く → 手を動かす → 聞く」を2セット回します。

| 時間 | 内容 |
|---|---|
| 0:00〜0:10 | 前回の宿題ふりかえり・今日のゴール確認 |
| 0:10〜0:20 | 説明①（10分） |
| 0:20〜0:40 | ハンズオン①（20分） |
| 0:40〜0:50 | 説明②（10分） |
| 0:50〜1:10 | ハンズオン②（20分） |
| 1:10〜1:25 | 質問・つまずき共有 |
| 1:25〜1:30 | 宿題の確認・次回予告 |

## 7. マカセルとの違い

| | マナベル（この講座） | マカセル |
|---|---|---|
| 形 | カリキュラムに沿って順番に学ぶ講座 | 作りたいもの1つに絞ったマンツーマン伴走 |
| 範囲 | Lark（ノーコード）→ AI・Claude Code → LINE連携まで、全体を一通り | Claude Code での開発が中心 |
| 向いている方 | 何から始めればよいか、全体像から知りたい方 | 作りたいものが決まっていて、早く形にしたい方 |

マナベル修了後に、作ったものを育てる場としてマカセルにつなぐ流れを想定しています。

## 8. 受講の約束

- 講師は「答えのコード」より「次に何を試すか」と「AIへの頼み方」をお伝えします。作るのは受講者ご自身です。
- APIキー・パスワードは講師にも共有しないでください（画面共有のときも隠してください）。
- 練習では本物の顧客情報を使わず、ダミーデータを使います。
- PC・ソフトの基本操作（ファイルの保存、ブラウザの使い方など）の個別レクチャーは対象外です。
