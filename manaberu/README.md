# マナベル — 2ヶ月で、自社のしくみを作れる「構築者」になる講座

> 「作ってもらう」から「自分で作れる」へ。
> Lark と AI を道具に、自社のサービスやアプリを自分の手で形にできる人を、社内に育てる講座です。

運営：ささエール（Office Plata）／講師：笹原 彰朗
形式：4〜6名の少人数オンライン／約2ヶ月（8週間）・全12回

---

## 1. この講座で目指すこと：「構築者」になる

マナベルのゴールは「ツールが使えるようになること」ではなく、**受講者が自社の「構築者」になること** です。

> **構築者**＝現場の困りごとを聞き取り、しくみを設計し、Lark と AI で作り、公開し、使われながら直し続けられる人

修了時に、次の6つを自分の手でやり終えていることを目指します。

| # | 構築者の力 | 修了時にあるもの |
|---|---|---|
| 1 | **聞き取る・決める**：業務から作るべきものを見つけ、AIと一緒に要件を1枚にまとめる | 作りたいもの設計シート |
| 2 | **Larkで組む**：BASEで台帳・フォーム・一覧・ダッシュボードをコードなしで作る | 自社用のBASE |
| 3 | **回す**：自動化・Bot通知・承認で「入力されたら知らせる・回す」流れを作る | 本番で動く自動化 |
| 4 | **AIで作る**：Claude Code に頼んでWebアプリを作り、インターネットに公開する | 公開URL |
| 5 | **つなぐ**：作ったアプリと Lark BASE・LINE を API でつなぐ | LINE → BASE → 通知が動くしくみ |
| 6 | **守り、育てる**：権限・個人情報・秘密情報を守り、改善を回し続ける | 運用ルール表と改善計画 |

最終回では、受講者それぞれが **自社で実際に使うしくみを1つ公開して発表** します。

## 2. マナベルの強み：まとめて学べる

AI研修、ノーコード研修、プログラミングスクールは、ふつう別々に受けることになります。マナベルでは、自社のしくみを作るのに必要なことを **1つの講座で、通しで** 学びます。

```
業務を整理する → Larkで組む → AIでアプリを作る → LINEとつなぐ → 安全に運用・改善する
（業務の棚卸し）  （ノーコード）   （Claude Code）     （LIFF）        （運用ルール）
```

- 学ぶ題材は、最初から最後まで **自社の実際の業務**。講座が終わったときには、勉強用のサンプルではなく、自社で使うしくみが残ります。
- 受託開発のように「直すたびに外注に頼む」状態にならず、**作れる人が社内に残ります**。

## 3. こんな方に

- 自社の業務を Lark で整えたいが、どこから手をつければよいか迷っている方
- 予約・受付・顧客管理・社内申請などを「自分たちの手で」作れるようになりたい方
- 社内でしくみ作りを任される担当者（DX担当・総務・店長など）
- AI（ChatGPT・Claude など）を触ってはみたが、仕事の「しくみ作り」にまで使えていない方
- プログラミング未経験の方も対象です（PCで文字入力・ファイル保存ができれば大丈夫です）

## 4. 8週間の流れ

前半はコードを書かない「Larkで組む」を週2回で進み、後半の「AIで作る」は、手を動かす時間を取るため週1回にしています。

| 週 | 回 | フェーズ | 内容 |
|---|---|---|---|
| 1 | 第1回・第2回 | 1 土台 | 作りたいものを決める／AIへの頼み方の型と要件づくり |
| 2 | 第3回・第4回 | 1→2 | Larkの基本と情報の置き場所／BASEの設計 |
| 3 | 第5回・第6回 | 2 Larkで組む | フォーム・ビュー・ダッシュボード／自動化・通知・承認 |
| 4 | 第7回 | 3 AIで作る | Claude Code入門とGit |
| 5 | 第8回 | 3 | Webに公開する |
| 6 | 第9回 | 3 | Lark BASEとAPIでつなぐ ＋ 個別レビュー（30分） |
| 7 | 第10回・第11回 | 4 サービスにする | LINEとつなぐ／安全な運用と改善 |
| 8 | 第12回 | 4 | 成果発表・構築者チェック |

詳しくは [curriculum.md](curriculum.md) を見てください。

## 5. 1回の進め方とサポート

1回90分。「聞く → 手を動かす → 聞く」を2セット回します。

| 時間 | 内容 |
|---|---|
| 0:00〜0:10 | 前回の宿題ふりかえり・今日のゴール確認 |
| 0:10〜0:20 | 説明①（10分） |
| 0:20〜0:40 | ハンズオン①（20分） |
| 0:40〜0:50 | 説明②（10分） |
| 0:50〜1:10 | ハンズオン②（20分） |
| 1:10〜1:25 | 質問・つまずき共有 |
| 1:25〜1:30 | 宿題の確認・次回予告 |

講座期間中のサポート
- 講座グループ（Lark）でのチャット質問（24時間以内に返信・土日祝を除く）
- 第6週に、1人30分の個別レビュー（作っているしくみを講師と一緒に見直す）

## 8. マカセルとの違い

| | マナベル（この講座） | マカセル |
|---|---|---|
| 形 | 4〜6名・2ヶ月で、構築者になるまでを一通り | 作りたいもの1つに絞ったマンツーマン伴走 |
| 範囲 | 業務整理 → Lark → AI・Claude Code → LINE連携 → 運用まで、まとめて | Claude Code での開発が中心 |
| 向いている方 | 何から始めればよいか、全体像から身につけたい方 | 作りたいものが決まっていて、早く形にしたい方 |

マナベル修了後に、作ったしくみをさらに育てる場としてマカセルにつなぐ流れを想定しています。

## 9. 受講の約束

- 講師は「答えのコード」より「次に何を試すか」と「AIへの頼み方」をお伝えします。作るのは受講者ご自身です。
- APIキー・パスワードは講師にも共有しないでください（画面共有のときも隠してください）。
- 練習では本物の顧客情報を使わず、ダミーデータを使います。本番の運用に入るのは、第11回で運用ルールを決めてからにします。
- PC・ソフトの基本操作（ファイルの保存、ブラウザの使い方など）の個別レクチャーは対象外です。
