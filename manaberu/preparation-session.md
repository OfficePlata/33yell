### 事前にやっておくこと（受講者向け案内文）
```

準備会の前に、次の4つだけ済ませておいてください（20分ほどです）。
1. Larkにログインできるか確認（会社のLarkの管理者に、BASEとアプリ作成ができるか聞いておく）
2. Claude（claude.ai）のアカウントを作り、Proプラン以上に加入

わからないところがあれば、講座グループで気軽に聞いてください。
（パスワードは送らないでください）
```

## インストール手順（当日、画面共有で一緒に）
> 公式の最新手順を、準備会の前日に講師環境で必ず確かめてから案内します（インストール方法は変わることがあります）。

1. ターミナルを開く
   - Mac：「ターミナル」アプリ
   - Windows：講師が当日案内する方法（公式手順に合わせる）
2. Claude Code の公式手順どおりにインストールする
3. `claude --version` と入力し、バージョンの数字が出ることを確かめる
4. `git --version` と入力し、バージョンの数字が出ることを確かめる（出ない場合は Git をインストール）
5. 作業用のフォルダを1つ作り、その中で `claude` と入力して起動し、ログインまで済ませる
6. 「こんにちは。このフォルダに hello.txt を作って」と頼んで、ファイルができることを確かめる

## 止まりやすいところ
| 症状 | 対応 |
|---|---|
| 会社のPCで管理者権限がなく、インストールできない | 会社の情報システム担当に相談してもらう。第4週までに解決しなければ、個人PCでの受講を相談 |
| Claude にログインできない／Pro に加入していない | 準備会の後で加入し、講座グループに報告してもらう |
| `command not found` と出る | ターミナルを開き直す。それでも出なければブレイクアウトで個別対応 |
