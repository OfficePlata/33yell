## マカセル（Claude Code マンツーマン伴走）— OFFICE PLATA の教育サービス

- 公開URL：officeplata.com/makaseru/（WordPress 固定ページ）
- キャッチ：「作りたいものを、自分の手で。」「迷ったら、マカセル。作るのは、あなた。」
- 内容：受講者が本当に作りたいもの（予約・受付フォーム、社内の管理画面、LINE連携の仕組みなど）を題材に、Claude Code で作りながら学ぶ。回答は方針・ヒント・レビューが中心で、代わりにコードを書くのは松の直接修正枠のみ
- 対象：外注は高いが自分で直せる状態にしたい人、Claude Codeを独学で止まった人、社内の仕組みを内製したい人。プログラミング未経験も可
- 比較の打ち出し：受託開発（60万円〜、直すたびに依頼、ブラックボックス）→ マカセル（完成品＋自分で作れる力が残る）

| プラン | 料金（税別） | 内容 |
|---|---|---|
| 単発レッスン | 30,000円／90分 | 作りたいものを分解し、最初の一歩を動かすまで。1ヶ月以内に竹・松へ移ると初月から差し引き |
| 梅 | 20,000円／月 | チャット質問し放題・返信48時間以内 |
| 竹（おすすめ） | 50,000円／月 | 返信24時間以内・月2回×60分セッション・コードレビュー・限定5枠 |
| 松 | 100,000円／月 | 返信当日中・毎週×60分セッション・コードレビュー・笹原の直接修正 月2時間まで・限定3枠 |

- 条件：月額プランは最低3ヶ月。Claudeの利用料は受講者負担。PC・ツールの基本操作レクチャーは含まない。同時に進める相談テーマは1〜2件まで。プラン変更は月単位
- 流れ：LINEで相談 → 単発レッスン → プラン選択 → 伴走スタート。基本オンライン（鹿児島・宮崎は対面も相談可）
- 自分で作るのが難しくなった場合は、受託開発への切り替えを案内する
- キャラクター：ささえもん（変形・色変え・要素追加は禁止）
