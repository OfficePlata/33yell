# Lark への蓄積ルール

AI社員の成果物は、Lark BASE「ささエール AI社員ログ」の「業務ログ」テーブルに1件ずつ貯める。あとで笹原さんが「先月の提案書」「確認待ち」などで探せるようにするため。

## 保存できるかの確認（仕事の最初に1回）

次のどちらかが使えれば保存できる。

- `node scripts/lark-log.mjs check` が「接続OK」を返す（PC の lark-cli、またはクラウドの LARK_APP_ID）

どちらも使えない場所（スマホの Claude アプリのチャットなど）では保存しない。その場合は成果物の最後に「Lark保存用」ブロック（下の JSON）を付けて、「PCかCodeで『このログをLarkに保存して』と貼れば保存できます」と一言添える。

## 何を保存するか

- 保存する：議事録、提案書、見積、レポート、調査、配信文、設計書、マニュアル、返信案、計画など、成果物として形になったもの
- 保存しない：雑談、質問への短い回答、途中の相談
- 笹原さんが「保存しないで」と言ったものは保存しない
- お金の実数・顧客の個人情報（電話番号・住所）は成果物から外すか伏せ字にしてから保存する

## 保存のしかた

1. 成果物を仕上げて笹原さんに見せる
2. 次の形の JSON を一時ファイル（例：/tmp/ai-log.json）に書く
3. `node scripts/lark-log.mjs add /tmp/ai-log.json` を実行する（スクリプトのパスはこのスキルのフォルダからの相対パス）
4. 「Lark に保存しました」と、表示された BASE の URL を最後に1行で伝える
5. 失敗したら、エラー文を短く伝え、「Lark保存用」ブロックを出して終える（何度もやり直さない）

```json
{
  "タイトル": "T社 初回相談の下調べ（2026-10-01）",
  "AI社員": "提案営業",
  "種別": "調査",
  "顧客・案件": "T社（ベーカリー）",
  "依頼内容": "明日の相談の下調べとヒアリングシート",
  "成果物": "（成果物の Markdown 全文）",
  "要判断": true,
  "判断事項": "勧めるプラン（導入伴走 or 顧問スタンダード）"
}
```

- 「AI社員」は SKILL.md の名簿の名前をそのまま使う（例：「CFO 財務・見積」）
- 「種別」は 議事録／提案書／見積／レポート／調査／配信文／設計書／マニュアル／返信案／計画／その他 のどれか
- 「要判断」は、笹原さんに上げる判断があれば true。ステータスは自動で「確認待ち」になる
- 「タイトル」は あとで検索しやすいように「誰の・何・日付」を入れる

## 貼り付けで頼まれたとき

「このログをLarkに保存して」と「Lark保存用」ブロックが貼られたら、中身を変えずにそのまま保存する。
